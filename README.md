# neyra.vision

Сайт Neyra Vision Studio для Казахстана. Статика, GitHub Pages, домен neyra.vision (DNS — Рег.ру).

- `/` — лендинг студии (RU/EN)
- `/mnvo/` — открытое предложение для МНВО РК + PDF
- `/mnvo/struktura/` — внутренний документ по коду + PDF
- `brand/` — логотипы Neyra Vision (PNG, AI, EPS) и Neyra Labs

Выкладка: `git push origin main`, GitHub Actions не нужен — Pages раздаёт ветку как есть.
